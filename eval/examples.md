# Verifier catches: real examples

Answers from the final naive-baseline run (Qwen3-32B with the stats table in its context, no query layer),
scored against the ground-truth result exactly as `eval/hallucination.py` scores them. The pipeline's own
answers produced no catches against ground truth apart from the one mislabelled question described in
`eval/README.md`, so all of these are naive answers.

Generated by `python -m eval.examples` (also run by `python -m eval.report`). Each excerpt is quoted
verbatim; the true values, the issues and the corrections are recomputed from the data and the current
verifier. In every case, whatever the verifier cannot rewrite is flagged, and the verified result is
appended to the answer.

## 1. A percentage that contradicts the model's own fraction

**Question:** lowest pass completion % among strikers

**Bad text** (excerpt of the naive answer):

> the lowest pass completion % is **-0.069** by Robert Lewandowski (Poland) with 92.4% pass completion (91 attempted, 65 completed)

**True values:**

- Robert Lewandowski: Passes completed / Passes attempted = 65/91 = 71.4%
- Ground truth: 1. Mitchell Duke (Australia) 52.9; 2. Youssef En-Nesyri (Morocco) 63.2; 3. Cho Kyu-Sung (South Korea) 65.0; 4. Olivier Giroud (France) 65.3; 5. Harry Kane (England) 66.0
- Ground-truth spec, in words: The 5 players with the lowest pass completion %, among strikers (ST), with at least 270 minutes (default threshold), World Cup 2022.

**What the verifier did:**

- number: "0.069": 0.069 does not appear in the verified result. **Flagged.**
- name: "Robert Lewandowski": Robert Lewandowski is not in the verified result. **Flagged.**
- team: "Poland": Poland is not in the verified result. **Flagged.**
- number: "92.4": 92.4 does not appear in the verified result. **Flagged.**

## 8. Partly caught: totals presented as per-90 values

**Question:** Which 5 Denmark players had the most progressive passes per 90?

**Bad text** (excerpt of the naive answer):

> 1. **Pierre-Emile Højbjerg** - 43.00 progressive passes/90  
> 2. **Kasper Schmeichel** - 1.00 progressive passes/90  
> 3. **Andreas Christensen** - 32.00 progressive passes/90

**True values:**

- Pierre-Emile Højbjerg: Progressive passes (simplified): 43
- Pierre-Emile Højbjerg: Progressive passes (simplified) per 90: 14.33
- Andreas Christensen: Progressive passes (simplified): 32
- Andreas Christensen: Progressive passes (simplified) per 90: 10.67
- Ground truth: 1. Pierre-Emile Højbjerg (Denmark) 14.33; 2. Joachim Andersen (Denmark) 13.67; 3. Andreas Christensen (Denmark) 10.67; 3. Christian Eriksen (Denmark) 10.67; 5. Kasper Schmeichel (Denmark) 0.33

**What the verifier did:**

- order: "Andreas Christensen": Andreas Christensen (rank 3) is listed after Kasper Schmeichel (rank 5). **Flagged.**
- Plus 2 other issues elsewhere in the same answer.

**Note:** Missed: 43.00 and 32.00 are the players' tournament totals, not per-90 values. A number counts as hallucinated only if it is not any true stat of its player, so these pass. Only the order is caught.
